# 习惯打卡

一个单文件的每日习惯打卡网页。双击 `index.html` 就能用，不需要安装任何东西，也不联网。

## 使用方法

1. 下载或克隆本仓库，双击 `index.html`（推荐用 Edge / Chrome 打开）。
2. 在底部输入框里添加想坚持的习惯，比如「喝水」「运动」「背单词」。
3. 每天点一下习惯右侧的圆圈就算完成，页面顶部会显示今天完成了几项。

## 功能

- 今日进度环：显示「已完成 / 总数」，以及「还差 N 项就满勤」，全部完成时显示庆祝文案。
- 添加、重命名、删除习惯；按名称自动匹配 emoji，也可以点图标手动更换。
- 点击整行即可打卡或取消打卡。
- 历史记录：每个习惯最近 7 天的打卡小格（实心＝已打卡，空心＝未打卡，浅灰＝习惯当天还没创建），以及「全部记录」里每天完成的习惯和完成数。
- 每天自动重置为未打卡状态，历史数据保留。
- 手机宽度下自适应排版。

## 数据存储

所有数据保存在浏览器本地存储里，键名为 `habit-tracker:v1`：

```json
{
  "version": 1,
  "habits": [{ "id": "…", "name": "喝水", "emoji": "💧", "createdAt": "2026-09-21" }],
  "logs": { "2026-09-21": ["habit-id-1", "habit-id-2"] }
}
```

- 数据只存在当前浏览器、当前设备中，换设备或换浏览器看不到。
- 清空浏览器数据会一起清掉打卡记录；删除某个习惯会同时删除它的历史。
- 如果浏览器禁止写入本地存储（例如隐私模式），页面会给出提示，此时记录在刷新后会丢失。

## 说明

- 整个项目就是一个 `index.html`：CSS 和 JavaScript 都内联在里面，没有任何第三方依赖、字体或图标库，也不会发起任何网络请求。
- 时区与日期以本机时间为准，跨过午夜后自动进入新的一天。
